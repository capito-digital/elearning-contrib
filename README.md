# elearning-contrib

This repository contains the open source part of the course-generator. It includes a version of the [adapt-learning](https://github.com/adaptlearning/adapt_framework) framework as well as a series of custom plugins and extensions.

## adapt-course-template

The `adapt-course-template` folder is a direct copy of the [adapt-learning](https://github.com/adaptlearning/adapt_framework) project.
